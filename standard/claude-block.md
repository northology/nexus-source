## Docs vault (nexus)
- `docs/` is this repo's vault, the current-state record. Notes follow `docs/_meta/`; check with `nexus docs check`.
- Standing rules live in `docs/governance/rules/` and are generated into `.claude/rules/nexus/`: change the note and
  run `nexus docs generate`, never the generated file.
- `docs/dev/context/` holds generated hubs, one per component: start there.
- `.scratch/` is untracked scratch space.
